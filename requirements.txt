# Windows Registry Change Monitoring System
# Core dependencies (all stdlib on Windows — no pip install needed)
# Listed here for documentation purposes.

# Standard library modules used:
#   winreg      — Windows Registry access (Windows only)
#   hashlib     — SHA-256 checksums
#   json        — Baseline serialization
#   logging     — Dual console/file logging
#   argparse    — CLI argument parsing
#   signal      — Graceful shutdown on Ctrl+C
#   time        — Polling interval sleep
#   re          — Log parsing
#   os, sys     — Filesystem and platform detection

# Optional — only needed if you extend the project:
# colorama>=0.4.6       # Cross-platform ANSI colors on older Windows
# schedule>=1.2.0       # Cron-style scheduling alternative to polling
# pywin32>=306          # WMI-based registry event subscriptions (advanced)
